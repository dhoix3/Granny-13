# ГРЕННИ 13 — побег от бабушки

Пародийная 3D-игра «в духе Granny», сделанная **полностью на C#** без единого стороннего
движка или библиотеки. Всё рисуется программным рендерером (raycasting), звук
синтезируется на лету, а главный персонаж — это **фотография из рабочей папки**
(`Granny.jpg`), вырезанная и превращённая в игрового монстра.

**Запуск:** двойной клик по `Granny13.exe` (нужен Windows 10/11, .NET Framework 4.x уже встроен).

---

## Что в игре

* **Два этажа** — дом (9 комнат) и чердак, между ними лестница-люк.
* **Гренни** — ходит по дому, слышит шум, видит свет фонарика, преследует, **ставит капканы**,
  проверяет шкафы и умеет подниматься на чердак.
* **Кошка Маруся** — живёт на чердаке, охраняет сундук с кодом. Шумишь — мяукает и зовёт
  Гренни. Принесёшь молока — засыпает и больше не мешает.
* **Три замка на входной двери:** висячий замок (ключ), ржавый засов (монтировка),
  кодовый замок (записка с кодом — она на чердаке у Маруси).
* **Дни.** Попался — потерял день. Кончились дни — конец игры.
* **4 сложности** с разной скоростью, зрением, слухом, числом капканов и дней.
* **Укрытия** — шкафы и под кроватью (Гренни может заглянуть, если видела, как ты прячешься).
* **Инвентарь**, фонарик с садящейся батарейкой, выносливость, миникарта, субтитры.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` / стрелки | ходить |
| мышь | осматриваться |
| `Q` / `R` | повернуть влево / вправо |
| `Shift` | бег (шумно, тратит выносливость) |
| `Ctrl` / `C` | красться (тихо) |
| `E` (или ЛКМ) | открыть дверь, обыскать шкаф, спрятаться, лезть на чердак, дать молоко |
| удержать `E` | обыск / открытие замка / люк |
| `F` | фонарик (свет видит Гренни!) |
| `M` | миникарта |
| `Пробел` | вырваться из капкана |
| `Esc` | пауза |
| `F11` | полный экран |
| `F1` | отладка |

## Как играть

1. Обыскивай шкафы, комоды, холодильник, ящики — в них лежат ключ, монтировка, молоко,
   батарейки и бинты. Содержимое каждый раз новое.
2. Найди **ключ от замка** и **монтировку** в доме.
3. Полезай на чердак (люк в коридоре, `E`), покорми **Марусю** молоком и забери из сундука
   **записку с кодом 137**.
4. Подойди к входной двери в прихожей и удерживай `E`, чтобы снять все три замка.
5. Не бегай без причины: она слышит каждый шаг.

## Технические детали

* Один exe (~2.8 МБ), без установки и зависимостей; картинки вшиты ресурсами.
* Рендер: софтверный raycasting 640×360 → апскейл 1280×720, освещение фонариком,
  туман, зерно, виньетка, спрайты с альфа-смешиванием, пол/потолок с текстурами.
* Текстуры генерируются процедурно в рантайме; обои — фрагмент халата Гренни с фото.
* Звук: свой мини-синтезатор (синусы/пила/шум, ADSR, фильтры) и микшер на `waveOut`,
  всё генерируется в памяти — ни одного звукового файла.
* AI: A*-поиск пути, слух по событиям шума, зрение с проверкой линии видимости,
  режимы патруль/расследование/погоня/поиск/подъём по лестнице.

### Сборка из исходников

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1        # соберёт Granny13.exe
powershell -ExecutionPolicy Bypass -File .\build.ps1 -Run   # собрать и запустить
.\Granny13.exe --autotest --nosound    # 46 автотестов логики -> granny13.log
.\Granny13.exe --soak --nosound        # прогон случайного геймплея -> soak.txt
.\Granny13.exe --shots --nosound       # скриншоты всех экранов -> screenshots\
.\Granny13.exe --audiotest             # проверка звукового движка -> audiotest.txt
```

### Структура

```
Granny13.exe          готовая игра
Granny.jpg            исходное фото персонажа
assets\               спрайты и иконки (вшиваются в exe)
src\                  исходники C# (Core, Textures, Renderer, World, Granny, Cat,
                      Game, UI, Audio, Program, Tests)
tools\                скрипты подготовки ассетов (Python/Pillow) и тестовые утилиты
screenshots\          скриншоты всех экранов
build.ps1             сборка (csc.exe из .NET Framework)
granny13.log          лог последнего запуска (пишется рядом с exe)
```

> Пародия. Все совпадения с настоящими бабушками случайны.
